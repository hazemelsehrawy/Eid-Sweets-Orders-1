## 🎯 البرومبت النهائي

اعمل لي موقع ويب متكامل لطلب حلويات وبسكوت العيد، بقاعدة بيانات حقيقية، فيه نوعين مستخدمين: **Guest (الزبون)** و **Admin (صاحب المحل)**.

### 🗄️ قاعدة البيانات

**Categories**: id, name, unit (كيلو/علبة/قطعة), price_per_unit, stock_quantity (اختياري للمخزون)

**Orders**: id, customer_name, phone_number, pickup_date, pickup_time, status (pending/accepted/rejected/preparing/ready/delivered), notes, total_price, created_by (guest/admin), created_at

**Order_Items**: id, order_id (FK), category_id (FK), quantity, subtotal

**Admins**: id, username, password_hash

### 1️⃣ صفحة الـ Guest
- فورم طلب: اسم الزبون، رقم موبايل، اختيار أصناف متعددة مع الكمية لكل صنف، تحديد ميعاد استلام (تاريخ + وقت)، ملاحظات
- عرض السعر الإجمالي تلقائيًا وهو بيختار الكميات
- بعد الإرسال: صفحة تأكيد فيها رقم الطلب
- **متابعة الطلب**: يدخل برقم الموبايل أو رقم الطلب ويشوف الحالة لحظيًا (قيد المراجعة → مقبول → قيد التحضير → جاهز → تم التسليم)

### 2️⃣ صفحة الـ Admin
- تسجيل دخول آمن (باسورد مشفر Hash)
- Dashboard فيه:
  - Badge بعدد الطلبات الجديدة اللي محتاجة مراجعة
  - قبول/رفض/تعديل كل طلب، وتغيير حالته عبر المراحل
  - إمكانية تسجيل طلب تليفوني بنفس فورم الطلب
  - لوحة تحكم لإدارة الأصناف (إضافة/تعديل/حذف صنف وسعره ومخزونه)
  - تنبيه لو صنف معين قرب يخلص من المخزون

### 3️⃣ صفحة كل الطلبات
- جدول/كروت لكل الطلبات مع فلترة (الحالة، التاريخ، اسم الزبون)
- **كاونتر تلقائي** لكل تصنيف حلويات (إجمالي الكمية المطلوبة والمقبولة)
- إجمالي الإيرادات المتوقعة من الطلبات المقبولة
- زرار تصدير الطلبات لملف Excel (يومي/أسبوعي)

### 4️⃣ صفحة إحصائيات
- رسم بياني للطلبات اليومية
- أكتر صنف مطلوب
- عداد تنازلي لعدد الأيام الباقية على العيد

### 5️⃣ ملاحظات تقنية
- تصميم عصري بألوان دافئة مناسبة للعيد، Responsive على الموبايل
- Realtime update للأدمن لما يجيله طلب جديد من غير ريفرش (لو ممكن)
